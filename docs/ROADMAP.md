# 开源化路线

## 已完成：第一轮通用化

- 清理原业务连接默认值与固定 HFMP 采集目标。
- 新增源库 Schema 查询与多选采集界面。
- 区分 Oracle / MySQL 连接表单与默认端口。
- 行业规则保留为可选模板，不自动识别自定义规则为行业模板。
- 整理不含原数据文件的工作副本，新增忽略规则。
- 容器构建、单入口代理、持久化卷、只读示例账号和合成数据。
- 密钥改为环境变量注入，默认本地监听。

## 发布首版前

1. 快照更新：按数据源、Schema、表名、字段名匹配对象，继承布局、人工备注与关系；删除/改名冲突显式展示，并增加事务回滚与回归测试。
2. 关系证据：样本量、双向包含率、父列唯一性、未匹配值；区分数据库外键、自动推荐、人工关系。
3. 项目导入导出：版本化格式、导入校验、默认排除凭据，完成往返测试。
4. 任务控制：进度、超时、取消与错误定位。
5. 数据源凭据采用认证加密；取消历史明文自动兼容路径，提供显式迁移。
6. Oracle / MySQL 真实环境集成测试和容器端到端验证。
7. 审核代码来源、素材和依赖许可；由所有者确定许可证后再公开发布。

## 后续按实际使用反馈推进

- PostgreSQL 适配。
- 多画布、快照差异、复合键与自关联分析。
- 关系和数据字典报告。
- 扩展式规则模板加载。

首版验收目标：陌生用户按 README 启动，通过示例库完成采集、关系发现、人工确认、保存与导出；当前尚未满足完整验收目标。
